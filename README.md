# Full Body Agency (FBA) in Functional Neurological Disorder (FND)

 date: 		29 October 2026
 authors: 	Michael Mouthon, michael.mouthon@unifr.ch			
 
This git hub repository contains the experimental script use during the data collection of the project "Altered full-body agency during locomotion in functional neurological disorder" - Stancu C. et al., submitted to the journal .......

This repository contains the Unity project (developped under the version 6000.0.38f1) used in real time Motion Tracking environment at the University of Fribourg (using a 24 cameras infrared OptiTrack motion-capture system).

The data recorded by this experimental script can be found on the following public repository: www.doi.org/10.5281/zenodo.23765711
